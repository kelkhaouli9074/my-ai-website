About MY AI

MY AI is a personal AI assistant designed to help users learn, create, ask questions, and explore ideas through artificial intelligence.

The project was created as a step toward learning, improving development skills, and building an independent AI platform.

Features

- AI-powered conversations
- Google Gemini API integration
- User authentication with Supabase
- Conversation history
- Image upload support
- Voice input and output
- Voice language settings
- Responsive chat interface

Technologies

- HTML5
- CSS3
- JavaScript
- Google Gemini API
- Supabase
- Vercel
- GitHub
